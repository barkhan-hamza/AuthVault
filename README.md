# AuthVault

AuthVault is a full-stack authentication and security system built to demonstrate modern authentication, authorization, and security practices.

## Tech Stack

### Backend
- Node.js
- Express
- PostgreSQL
- pg
- Argon2
- JWT
- Zod
- Helmet
- CORS
- Express Rate Limit

### Frontend
- React
- TypeScript
- Axios

### Testing
- Vitest
- Supertest

### DevOps
- Docker
- Docker Compose

## Project Status

🚧 AuthVault is currently under active development.

## Planned Features

- User signup and login
- Password hashing with Argon2
- JWT access tokens
- Refresh token rotation
- Token reuse detection
- Role-based access control
- Permission system
- Active session management
- Admin dashboard
- Audit logging
- Security hardening
- Automated security tests
- Docker setup
- Production deployment
